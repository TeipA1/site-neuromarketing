# Фокус — лаборатория взгляда

Учебное исследование по нейромаркетингу. Сайт следит за взглядом через обычную веб-камеру и проверяет вывод статьи Pieters & Wedel (2004, *Journal of Marketing*): **чем больше площадь текста в рекламе, тем больше внимания он получает**.

Сайт создал: **Ахметов Теип**.

## Как устроен тест

1. Участник разрешает доступ к камере и проходит настройку по 9 точкам.
2. Листает ленту из 8 рекламных постов (максимум 15 секунд на пост).
3. Три поста — целевые (кофейня «Тёплый Час», кроссовки «Лёгкий Шаг», пиццерия «Сытый Кот»), каждый в двух версиях:
   - **А** — мало текста (одна строка);
   - **Б** — много текста (крупный заголовок и абзац).
4. Группа 1 видит версии А-Б-А, группа 2 — Б-А-Б; группа выбирается случайно.
5. Сайт считает время взгляда на зонах «бренд / картинка / текст», рисует карту взгляда и отправляет результаты в Google Таблицу.

Видео с камеры обрабатывается только в браузере и никуда не отправляется.

## Файлы

| Путь | Что это |
|---|---|
| `index.html`, `style.css`, `app.js` | сам сайт |
| `ads/` | макеты рекламы (`c1–c3` — целевые, `f1–f5` — фоновые) |
| `lib/webgazer.js` | WebGazer.js (Brown University, GPLv3) — отслеживание взгляда |
| `models/` | модели распознавания лица (хранятся локально, чтобы тест запускался быстро) |
| `apps-script/Code.gs` | скрипт Google Таблицы, который принимает результаты |

## Публикация

Сайт статический: подходит любой хостинг с HTTPS (Vercel, Netlify, GitHub Pages). Камера работает только по `https://` или на `localhost`.

Ссылка на таблицу задаётся в `app.js` → `CONFIG.SHEETS_URL`.
